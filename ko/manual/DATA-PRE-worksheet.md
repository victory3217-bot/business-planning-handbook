# 가설·조사 현황표 — 콘텐츠 비즈니스 예비창업자용 (고객·경쟁·반응)

> **대상:** 영상·강의·전자책·뉴스레터·웹툰·앱 같은 콘텐츠 비즈니스를 준비 중인 예비창업자용 워크시트다. 이미 운영 중이라 자기 매출·고객 숫자가 있다면 「데이터 현황표」를 쓴다.

> **성격:** CH03·CH05~CH08에서 세운 BM 가설을 내가 모은 조사 자료와 간이 반응 숫자로 확인하기 위한 보조 워크시트다. 지표 이름과 계산식은 이 워크시트에서 쓰기 위한 〔제안〕이며 원본 지식 노트의 표준 정의가 아니다.

> **AI에 올리기 전:** 이 표에는 공개된 정보와 내가 직접 모은 익명 기록만 적는다. 인터뷰 대상의 이름·연락처·계정명은 적지 않는다.

---

- [ ] 공개된 정보와 내가 직접 모은 익명 기록만 적었다
- [ ] 인터뷰 대상의 이름·연락처는 적지 않았다
- [ ] 조사한 숫자마다 출처와 기준일을 적었다
- [ ] 기간과 단위(원/건/명/회)를 표 머리글 기준으로 통일했다

| 지표 | 계산식 〔제안〕 | 내 값 | 근거 상태 (사실 / 가정 / 확인 필요) |

> 점검 포인트: 계산은 스프레드시트나 계산기로 하고, AI 계산은 계산식을 보여 달라고 해서 직접 다시 확인한다.

## 5. 곱셈 사슬

연 매출을 다섯 항의 곱으로 나눠 놓고, 보수적인 값과 기준 값으로 두 번 채운다.

```
보수: 타깃 수 ( ____ ) × 내 콘텐츠를 알게 되는 비율 ( ____ ) × 전환율 ( ____ ) × 1인당 구매 횟수 ( ____ ) × 가격 ( ____ ) = 연 매출 ( ____ )
기준: 타깃 수 ( ____ ) × 내 콘텐츠를 알게 되는 비율 ( ____ ) × 전환율 ( ____ ) × 1인당 구매 횟수 ( ____ ) × 가격 ( ____ ) = 연 매출 ( ____ )
```

- 가장 먼저 바뀔 가정은: ______________________________
- 그 가정의 근거 상태 (사실 / 가정 / 확인 필요 중): ______________________________

> 점검 포인트: 이 곱셈은 예측이 아니라 가정을 드러내는 틀이다. 곱하는 숫자마다 근거 상태를 붙인다.

## 6. 가격·손익분기 간이

가격과 비용을 적고, 한 달에 몇 개를 팔아야 비용을 넘기는지 계산한다.

| 항목 | 내 값 | 근거 상태 |
|---|---|---|
| 판매가(원) | | |
| 판매당 변동비(원: 결제 수수료·외주 등) | | |

| 단위 공헌이익 = 판매가 − 변동비 | | |
