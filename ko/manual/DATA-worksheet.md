# 데이터 현황표 — 콘텐츠 비즈니스 사업자용 (매출·고객·트래픽)

> **대상:** 영상·강의·전자책·뉴스레터·웹툰·앱 같은 콘텐츠 비즈니스를 운영하는 사업자용 워크시트다. 기업 신사업팀이 콘텐츠 사업을 검토할 때는 "나·내"를 "우리 팀"으로 바꿔 읽는다.

> **성격:** CH05~CH08에서 만든 BM 가설을 내 실제 숫자로 확인하기 위한 보조 워크시트다. 지표 이름과 계산식은 이 워크시트에서 쓰기 위한 〔제안〕이며 원본 지식 노트의 표준 정의가 아니다.

> **AI에 올리기 전:** 이 표에는 집계한 숫자만 적는다. 고객 이름·연락처·이메일·계정명은 적지 않는다.

## 2. 핵심 지표 현황표

기간마다 한 행씩, 12개 기간의 숫자를 적는다. 기간은 월이나 주 중 하나로 통일한다.

> 열 설명: 노출·방문은 영상 조회·페이지 방문·앱 방문 중 내가 쓰는 하나다. 신규 고객은 새 구독자·가입자·첫 구매자 중 하나다. 재구매·재방문 고객은 같은 고객이 다시 산 수 또는 돌아온 수다. 비용은 제작비·광고비·플랫폼 수수료의 합이다.

## 3. 파생 지표 계산

위 표의 숫자로 아래 지표를 계산해 적는다. 근거 상태는 사실 / 가정 / 확인 필요 중 하나로 표시한다.

| 지표 | 계산식 〔제안〕 | 내 값 | 근거 상태 (사실 / 가정 / 확인 필요) |
|---|---|---|---|
| 전환율 | 신규 고객 ÷ 노출·방문 | | |
| 객단가 | 매출 ÷ 결제 건수 | | |
| 재구매율 | 재구매·재방문 고객 ÷ 전체 고객 (정의를 메모에 적는다) | | |
| 비용률 | 비용 ÷ 매출 | | |
| 고객 1명당 획득비용(CAC, 간이) | 마케팅·광고비 ÷ 신규 고객 | | |
| 고객 1명당 간이 LTV | 객단가 × 평균 구매 횟수 × 마진율 | | |
| 최근 3개월 매출 증감 | 최근 3개월 합 ÷ 이전 3개월 합 − 1 | | |

> 점검 포인트: 계산은 스프레드시트나 계산기로 하고, AI 계산은 계산식을 보여 달라고 해서 직접 다시 확인한다.

## 4. 매출 분해

매출을 네 항의 곱으로 나눠 보고, 최근 기간과 이전 기간을 같은 방식으로 채운다.

> 간이 분해 〔제안〕: 전환율과 1인당 구매 횟수는 3번의 정의와 같게 센다. 정확히 맞아떨어지지 않으면 차이를 숨기지 말고 메모에 적는다.

```
최근 기간: 매출 = 노출·방문 ( ____ ) × 전환율 ( ____ ) × 객단가 ( ____ ) × 1인당 구매 횟수 ( ____ )
이전 기간: 매출 = 노출·방문 ( ____ ) × 전환율 ( ____ ) × 객단가 ( ____ ) × 1인당 구매 횟수 ( ____ )
```

- 가장 많이 달라진 항은: ______________________________
- 그 항이 달라진 이유 가설 한 줄: ______________________________
