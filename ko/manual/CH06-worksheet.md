# CH06 원가·가격·수익모델 점검

> 출처: Chapter 6 / KM043–KM054 (business-planning-handbook)
> 이 워크시트는 KM043–KM054에 담긴 질문과 프레임워크를 그대로 작성란 형태로 옮긴 것이다. 새로운 방법론을 추가하지 않았다.

## 1. 활동에서 비용 추정하기 (KM044, KM045)

사업계획의 실행활동을 나열하고, 각 활동에 필요한 비용을 적는다.

| 활동 구분 | 세부 활동 | 필요 비용 항목 | 예상 금액 |
|---|---|---|---|
| 기술개발 | (예: 연구인력, 견본, 재료, 기술도입, 위탁개발, 장비, 정보활용) | | |
| 제품생산 | (예: 재료, 생산인력, 임차, 외주가공, 운반·보관·포장비) | | |
| 판매유통 | (예: 시장조사, 유통망 확보, 광고, 전시회, 견본, 판매인력) | | |

원가구조를 아래 항목으로 정리한다.

- 고정비(생산·판매량과 무관하게 일정하게 발생하는 비용):
- 변동비(생산·판매량에 따라 변하는 비용):
- 직접비(특정 제품·서비스에 직접 추적 가능한 비용):
- 간접비(여러 부서·제품에 걸쳐 귀속이 어려운 비용):
- 제조원가(재료비+노무비+제조경비, 또는 유통업의 매입원가):
- 판매관리비(판매·운영에 드는 비용):
- 총원가(제조원가/매입원가 + 판매관리비):

## 2. 고객가치 기반 가격결정 (KM046)

- 고객은 우리 상품·서비스에서 어떤 문제를 해결하거나 어떤 가치를 얻는다고 느끼는가?
- 고객이 받아들일 수 있는 가격대와 지불의사는 얼마인가? (고객조사·시장반응 테스트 결과)
- 그 가격에서 사업성이 성립하도록 원가와 상품구성을 어떻게 조정할 수 있는가?
- 우리가 높은 가격을 정당화하려면 어떤 가치의 근거(제품, 채널, 서비스, 브랜드)를 설계·증명해야 하는가?

## 3. 경쟁 기반 가격과 포지셔닝 (KM047)

- 우리와 동일한 고객세그먼트에게 유사한 고객가치를 제공하는 실제 경쟁자(대체재 포함)는 누구인가?
- 그 경쟁자들의 가격 수준은 어떠한가?
- 우리는 저가전략을 택하는가, 고가전략을 택하는가? 그 선택이 요구하는 조건(저가: 영업이익률 감수·자금 리스크 / 고가: 제품·서비스·고객경험·채널·브랜드)은 갖춰져 있는가?
- "얼마 받을 것인가?"가 아니라 "어떤 고객에게 어떤 가치로 기억되고 싶은가?"에 대한 우리의 답은 무엇인가?

## 4. 채널과 가격구조 (KM048)

- 우리가 사용하는 채널은 직접채널인가, 간접채널인가, 혹은 혼합인가?
- 간접채널을 사용한다면 수수료·유통마진은 얼마이며, 가격구조에 반영되어 있는가?
- 직접채널을 사용한다면 고객획득·배송·서비스를 스스로 감당할 자원이 있는가?
- 소비자가격과 실판매가 사이에 할인·커미션·위탁판매수수료 등을 둘 구간이 필요한가? 필요하다면 그 구간은 얼마인가?

## 5. 고객관계 비용 (KM049)

- 고객을 획득하는 데 드는 비용(인력, 시스템, 프로모션)은 얼마인가?
- 구매경험을 관리하고 재구매·추가구매로 이어지게 하는 데 드는 비용은 얼마인가?
- 이 비용은 현재 가격구조(원가+마진) 안에 반영되어 있는가?

## 6. 수익원과 수익모델 (KM050)

다음 질문에 답한다.

- 누가 돈을 내는가?
- 무엇에 돈을 내는가?
- 얼마를 내는가?
- 언제 돈이 들어오는가?
- 한 번 내는가, 반복해서 내는가?

해당하는 수익원 유형을 표시한다 (복수 선택 가능): □ 물품판매 □ 이용료 □ 가입비 □ 대여·임대 □ 라이선싱 □ 중개수수료 □ 광고 □ 기타( )

## 7. 단발성 수익과 반복적 수익 (KM051)

- 우리 사업은 상품을 한 번 판매하고 관계가 끝나는 모델인가, 구매 이후에도 지속적인 관계관리로 반복매출이 발생하는 모델인가?
- 고정비를 부담하는 구조라면, 매번 새로운 고객을 확보해야 하는가 아니면 기존 고객이 다시 매출을 만드는가?
- 최초 구매가격 외에 고객관계에 필요한 비용과 반복수익의 가능성을 함께 고려했는가?

## 8. 가격 메커니즘 (KM052)

우리 사업의 가격 부과 방식을 표시한다: □ 고정가격 □ 협상가격 □ 물량별 단가(B2B) □ 입찰/조달조건(B2G) □ 기타( )

- 이 방식은 거래당사자의 협상력, 재고, 시기, 수요와 공급, 입찰조건 중 무엇과 밀접하게 연결되는가?

## 9. 세 재무 렌즈 (KM053)

| 관점 | 확인할 질문 | 답 |
|---|---|---|
| 손익 | 가격·판매량·원가·판매관리비를 고려할 때 마진은 얼마나 남는가? | |
| 자산 | 사업활동을 통해 어떤 자산(가치)이 축적되는가? | |

## 10. 사업타당성으로 넘어가기 전 점검 (KM054)

다음 세 가지가 정리되었는지 확인한다.

- [ ] 고객과 가치에 근거한 가격(P)이 정리되었다.
- [ ] 그 가격에서 사업을 지속할 수 있게 만드는 비용과 마진 구조가 정리되었다.
- [ ] 고객이 무엇에 어떻게 비용을 지불하는지를 설명하는 수익모델이 정리되었다.

세 가지 중 정리되지 않은 항목이 있다면, 시장규모(P×Qty) 계산으로 넘어가기 전에 위 1~9번 항목으로 돌아가 다시 점검한다.
