# CH08-EX01. 영양제 현장검증 피보팅 사례

- **관련 Chapter:** CH08 실행·검증·피보팅하며 수정한다
- **관련 MN:** MN08 실행·검증·피보팅·사업계획
- **관련 KM:** KM068 데이터 기반 피보팅

## 무엇을 설명하는 사례인가

"사람들이 추억 때문에 옛 영양제를 다시 찾을 것"이라는 가설이 실제 영업 과정에서 어떻게 깨졌는지를 보여주는 사례다. 사업팀은 고객이 과거의 추억을 이유로 제품을 다시 찾을 것이라 가정했지만, 실제 현장검증에서 고객은 추억보다 효능을 더 중요하게 보았다. 이 데이터에 따라 홍보문구와 고객 접근방식을 수정해야 했다.

이 사례는 피보팅이 "처음 생각을 버렸다"는 의미가 아니라, "새로운 데이터가 기존 가설을 수정한 결과"라는 원칙을 보여준다. 즉 피보팅의 기준은 새로운 아이디어가 떠올랐는가가 아니라, 실제 데이터가 기존 가설(이 경우 "추억"이라는 구매 동기 가설)을 흔들었는가에 있다.

## 참고

같은 KM에는 갤러리 사례도 함께 제시되어 있다. 현재 수익원과 원하는 사업의 모습을 정의한 뒤 작은 실행을 하고, 시장반응이 나타나자 타겟고객과 핵심자원의 관계를 다시 조정한 사례로, "한 번 잘 작동한 비즈니스모델도 시장이 움직이면 다시 바뀔 수 있다"는 점과 "피보팅은 일회성 이벤트가 아니라 사업개발 과정의 정상적인 학습 메커니즘"이라는 점을 함께 보여준다.
