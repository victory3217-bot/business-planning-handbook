## 이 교재의 목적

사업기획의 8개 핵심 영역 — 사업의 기준, 사업기회 탐색, 고객·문제 정의, 가치제안·경쟁우위·포지셔닝, 비즈니스모델, 원가·가격·수익모델, 사업타당성·유효시장, 실행·검증·피보팅 — 을 하나로 연결된 학습 흐름(Learning Path)으로 재구성한 공개교재다. 아이템을 먼저 정하는 방식이 아니라, 기준 → 기회 → 고객 → 가치제안 → 비즈니스모델 → 가격 → 타당성 → 실행·검증으로 이어지는 판단 순서를 따른다.

## 대상 독자

사업개발의 체계적 방법을 처음 배우는 예비창업자·초기창업자, 또는 초기 사업기획을 담당하는 비전문가. 특정 산업 경험이나 기술 전문성을 전제하지 않는다.

## 8 Chapter Learning Path

| Chapter | 제목 |
|---|---|
| [CH01](chapters/CH01.md) | 사업의 기준을 정한다 |
| [CH02](chapters/CH02.md) | 사업기회를 찾고 선택한다 |
| [CH03](chapters/CH03.md) | 고객·구매자·문제를 정의한다 |
| [CH04](chapters/CH04.md) | 가치제안·경쟁우위·포지셔닝을 만든다 |
| [CH05](chapters/CH05.md) | 비즈니스모델을 설계한다 |
| [CH06](chapters/CH06.md) | 원가·가격·수익모델을 설계한다 |
| [CH07](chapters/CH07.md) | 사업타당성과 유효시장을 검증한다 |
| [CH08](chapters/CH08.md) | 실행·검증·피보팅하며 수정한다 |

각 Chapter는 동일한 문서 구조(이 장에서 답할 질문 / Learning Objectives / 핵심 개념 / 프레임워크 / 적용 과정 / 흔히 발생하는 판단 오류 / 실무 적용 질문 / 다음 Chapter와의 연결 / 핵심 정리)를 따르며, Chapter당 실습 [워크시트](manual/) 1개와 대표 [사례](examples/)를 포함한다.

## 출처 정책

이 교재는 저자가 운영하는 내부 Knowledge Base의 내용을 학습자용 교재 형식으로 재구성한 것이며, 외부 리서치·웹검색·일반지식 보충 없이 만들어졌다. 자세한 Chapter-출처 대응관계는 [`../source-map.md`](../source-map.md)를 참고한다.
